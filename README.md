# 第七史诗 · 统一推进助手

同一个轻量桌面界面选择 **MuMu / PC 桌面端** 与 **主线 / 普通深渊**；共用实例绑定、观察、启动、暂停、继续、停止、关数上限、预览和日志。不再分别启动主线脚本和深渊面板。

## 日常入口

双击 **`Assistant.cmd`**。

1. 打开已登录的游戏；选择客户端及具体实例。只有唯一目标时自动填入；多个目标必须手选，运行时不会擅自切换。
2. 选择“主线推进”或“普通深渊”。MuMu 使用 ADB；PC 可选后台窗口消息（实验性）或前台兼容模式。
3. 先用“仅观察”确认画面识别。正式推进时取消该选项，确认队伍/原生自动战斗，设置本次上限，点击“开始推进”。新后台模式首次建议设为1层。
4. 暂停保留当前会话，点击“继续运行”重新截图；停止不会关闭游戏或清空历史。

窗口按 Windows 可用工作区限制大小，内容可滚动，开始/暂停/停止固定在底部；不缩小字体硬塞内容。

`Start.cmd`、`PCStart.cmd` 以及旧深渊助手的本机 `Launch.cmd` 都是同一界面的入口别名，不是独立软件。原维护 CLI 保留用于只读检查、人工补过核验等高级维护，不用于日常分开启动。

## 实际支持与验证范围

| 组合 | 当前状态 |
|---|---|
| MuMu × 主线 | 复用原来已实机运行的 ADB 主线状态机及完整历史；本次未重新打开模拟器跑关 |
| MuMu × 普通深渊 | 已接入同一后端和普通深渊规划器；**尚未在 MuMu 实机验收**，无法确认界面时停止 |
| PC前台 × 普通深渊 | 沿用已实机通关的深渊状态机；新统一执行器尚未重新做完整战斗验收 |
| PC后台 × 普通深渊 | 已实测失焦截图、上方普通入口、选层、选择队伍、准备页及返回；**停在开战前，整场后台推进未验收** |
| PC × 主线 | 接入原有账号自动核对、校验链和记录；保留原战败/未结算拦截；**完整后台主线未验收** |

原主线的全部通关记录原位保留。手动过掉原失败关后，点击“开始推进”会自动核对当前账号与原关两帧绿色通关勾，核实后补记为手动通关，不再要求手工编辑记录。未核实仍拒绝重试；换客户端、新建空记录或清除 STOP 均不能绕过历史。若原关不在可见范围或已经跨Episode，请先在地图选中原关再开始核对。

## 后台模式边界

- MuMu 的输入与截图发给已绑定 Android 实例，不移动电脑鼠标；模拟器内仍需保持授权游戏为前台应用。
- PC后台使用 `PrintWindow` 取客户区、`PostMessage` 发送窗口消息；不调用 SetForegroundWindow/SetFocus/AttachThreadInput，不伪造 WM_ACTIVATE，不注入、不读写游戏内存，不自动回退到 SendInput。
- 本机已验证 GLFW30 窗口的无焦点导航。接口返回成功只说明消息已投递，必须由后续截图验证游戏实际变化。
- **PC后台不支持最小化**；任意遮挡/长时间挂机/拖动/CG长按/维护后的兼容性均不能视为已完整验收。
- 进程寿命、窗口身份、尺寸/DPI、截图新鲜度、STOP和任务校验继续生效；窗口或画面不确定即停。

## 安全与隐私

- 只允许正常关卡入场消耗；不购买/兑换体力、不复活、不重试失败关卡、不改队伍或养成。
- 仅上方普通深渊，禁止下方挑战模式；未知确认框不盲点。
- 主线沿用全部 attempted/completed/active/last_cleared；深渊入场前另行持久化意图，结果不明不重复开战。
- 一个界面只运行一个任务，并与旧主线共享进程锁，避免双写或双客户端同时输入。
- 配置、账号历史、截图、OCR、日志、设备信息、本机识别图块和第三方运行库均不提交 Git、不上传。
- 使用现有本机 Python/Tk 与工作运行库，没有为本次整合下载内容或修改代理、安全设置。

当前为既有本机运行环境的整合版；新用户首次安装向导、跨机器便携打包、四种组合的完整实机矩阵不在已验收范围内。

## 文件与测试

- `assistant_app.py`：唯一图形界面；`assistant_config.py`：选择/迁移/工作区策略
- `assistant_worker.py`：单任务执行、暂停与停止；`assistant_transport.py`：共享客户端接口
- `pc_message_backend.py`：独立的显式后台消息适配；`pc_backend.py`：原前台兼容/账号授权适配
- `runner.py`：原主线状态机；`abyss_core.py` / `abyss_templates.py`：普通深渊状态机与本机识别图块
- `.local/assistant/`：本机设置、会话与日志；原主线状态目录仍原位引用，不复制成空记录

离线测试不产生游戏输入：

```powershell
py -3.12 -B -X utf8 -m unittest discover -s tests -v
```

真实素材不分发。`EPIC7_PRIVATE_FIXTURES`、`EPIC7_PC_FIXTURES`、`EPIC7_ABYSS_FIXTURES` 可指向各自的私有回归目录；缺少素材时明确跳过，不当作通过。工作运行库路径沿用已有 `.local/python-path.txt`；GUI需包含Tkinter的本机Python，可用 `EPIC7_GUI_PYTHON` 指定。

详细验证见 [统一与后台输入记录](docs/UNIFIED_ASSISTANT.md)，历史更新见 [CHANGELOG](CHANGELOG.md)。
