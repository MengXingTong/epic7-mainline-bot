# v1.4.17-preview 发布验证与边界

本版收录MuMu实际前台包发现、管理器冗余门槛移除、同布局行走地图/地区身份、准备期过期恢复、独立留证及未知页面诊断。渠道服尚未实机验收；PC仍实验性。本发布流程只操作源码、合成测试、包和GitHub，不操作游戏。

## 关键行为

- MuMu先打开游戏再刷新，按所选实例当前前台组件的实际包名绑定，不要求默认包或手填渠道名单；管理器字段不否决在线实例，当前应用变化及未知页面仍不输入。
- 历史dispatch没有准备ID只跳过不存在的准备计划，不阻止独立地图完成事实；不自动创建准备ID、恢复旧归档、重发耗资源入场或改写sent。
- 首次入场实际调用边界、关键意图/证据写入、当前控件、资源/付费、防重复、目标/几何/帧时效、STOP与并发保护保留。
- 同布局行走地图有独立地区/节点历史；圆盘只用于免费选点，实际准备身份/费用与独立结算仍核实。新行走账本的容量接续、上级总览自动导航、全部特殊节点与跨地区完整闭环尚未全面验收。

## 实际验证

完整源码离线1865项（1749通过、116条件跳过）及真实Tk隐藏窗口53项通过；干净完整包、中文空格路径、v1.4.16覆盖更新冷自检通过，合成旧失败/active/证据/STOP/.local逐字节保留；3169项逐文件清单和隐私白名单核实，运行库与上版一致，无新下载。提交快照、最终ZIP与远端Windows CI实际结果见Release。

原先全量中的5项错误已修复并包含在本轮通过结果中：旧dispatch无准备ID兼容处理，以及模拟输入调用边界测试夹具；生产资源/目标/输入和发送不明保护不放宽。最终ZIP、独立Git提交快照和主分支/标签的远端Windows CI通过后才公开附件，以Release所附实际结果为准。

## 更新与分发

使用独立v1.4.17-preview标签和干净完整包、update覆盖包及SHA256SUMS.txt，不覆盖旧附件。先停止任务并关闭所有旧助手，在原目录覆盖更新；保留.local、state.json、入场/失败/通关历史和全部证据，旧worker不热加载。

只提交白名单源码、测试和说明。包不含账号、完整截图/OCR、运行日志、设备绑定、配置、凭据或私人一次性许可；第三方运行库仅完整附件分发，更新包不含运行库。本机有限MuMu七节点实测见WALKING_MAP_VALIDATION_2026-11-09.md；这些记录不等于渠道服、跨机器或所有地图验收。
