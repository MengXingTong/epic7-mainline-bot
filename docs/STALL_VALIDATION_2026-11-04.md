# 卡住问题排查与验证 — 2026-11-04

## 已确认的问题

| 问题 | 证据与修复 |
| --- | --- |
| 正常过渡被当作未知弹窗 | 保存画面中CLEAR盖住结算页，OCR漏读道具标题，只保留底层确认。稍后只读截图可完整识别结算。新增连续稳定观察，不再凭过渡中的单帧转人工等待。 |
| 画面变化被固定时间截断 | 主线/剧情以最后一次明显画面或控件变化为起点等待稳定；变化可以持续任意时长。未知弹窗稳定4秒后再按原规则处理，其他已知画面要求连续稳定观察。用户接管输入时先让行，恢复后重新截图。普通深渊的未确认/容量弹窗共用观察门槛。 |
| 规划前截图过期也直接暂停 | 新鲜度检查前移到规划之前。仅单纯超龄的未消费帧持续重取；原5秒时效不变。明确未发送的普通地图/辅助选队点击，即使在保存记录后才超龄，也重新读取并规划。几何/进程变化、入场意图和发送不明仍等待处理；不扩展not_sent例外。 |
| 确认按钮与结算布局对应不足 | 道具标题、战斗结果与唯一右下确认共同验证，三者有置信度门槛；普通未知确认/取消优先于底图识别。中心确认、重复确认或低置信确认不再误入结算。 |
| 运行按钮灰字绿底 | Tk按钮明确指定激活及禁用文字颜色，主按钮运行/等待时保持白字；增加“等待画面稳定…”状态及暂停/停止支持。 |

画面稳定只是必要的观察条件，不是输入授权。资源、容量、战败、当前关验证、防重复、窗口身份与帧新鲜度仍各自检查。稳定的未知弹窗仍需用户处理；本次未修改购买、复活或重复关卡授权。

## 验证结果

- 修复前基线：561项，481通过、80明确跳过。
- 补充导航超龄修复后工作运行库：590项，509通过、81明确跳过。
- 独立GUI运行库：30项全部通过；与上项合计539项独立用例通过，51项私有素材缺失跳过。
- 不含未完成次元探查的独立发布快照：547项，工作运行库434通过、113跳过，另28项GUI全部通过；合计462通过、85项私有素材缺失跳过。
- 新增29项覆盖变化持续数小时、缓慢渐变、轻微OCR位置抖动、控件移动、稳定未知弹窗、停止中断、持续过期零输入、几何/进程变化、规划后意图保留及按钮状态。
- 本次保存的过渡帧和随后完整结算帧进行离线顺序回放：只在稳定完整结算上规划确认和记成功；全部使用模拟输入及合成历史。
- 对已核验游戏窗口进行6帧只读采样，当时游戏已继续进入战斗；每帧均判断为仍在变化，没有发送任何游戏输入。它证明动态画面会等待，不能证明修复后完整战斗流程已实机通过。
- 真实Tk窗口中检查推进、等待稳定、暂停后三种按钮截图；使用虚拟工作进程，不启动任务。
- 后续旧worker再次发生辅助选队页超龄：事件日志显示普通导航记录已写、输入因帧过期被拒绝，暂停界面还显示上一帧地图。补入4项保存后超龄/新帧目标/入场不放行/记录及几何失败回归；暂停现在显示实际处理页面。发布源码另从独立快照复验，数量见Release说明。
- `git diff --check`通过。真实截图、OCR、日志和设备配置仅保存在本机私有目录，不纳入源码或包。

## 生效范围与限制

此次改动纳入v1.4.8-preview。已运行的助手和worker不会热加载；当前战斗结束后停止任务、关闭并重新打开助手，再显式开始。未由排查过程恢复任务、发送点击、清空或补记真实历史。

PC仍为实验性。稳定性阈值允许轻微装饰变化，但尚未覆盖所有分辨率、GPU、游戏布局和动画；没有宣称修复后整场PC/MuMu战斗验收。未完成的次元探查独立worker未接入本次策略。
