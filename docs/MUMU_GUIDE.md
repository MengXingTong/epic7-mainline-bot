# MuMu《第七史诗》主线脚本 · 分享版 v1.0

## 先看这里

这是 **Windows 64位电脑 + MuMu模拟器** 使用的本地主机脚本，**不是手机APK/Auto.js脚本**。离线完整版已附Python 3.12和OCR依赖，不需要自行安装Python，不需要API Key，也不会联网调用AI。

适配的是《第七史诗》**简体中文、Episode章节列表**这套界面。本机实测为MuMu国际版Android 15实例；其他MuMu版本、渠道服、英文UI、旧地图或更改后的界面不保证兼容。**游戏分辨率请使用16:9横屏**（如1600×900或1280×720）。不要直接用在不同界面的游戏/客户端上。

分享包不含账号、进度、日志、截图、密码和游戏/MuMu本体。首次运行会在本目录创建收件人自己的记录，**不同账号应各用一个独立目录**。

## 开始使用

1. **完整解压**压缩包到有写入权限的目录；不要在压缩包预览里直接双击。
2. 打开MuMu与游戏，进入正确账号的大厅或主线页面。请自行确认模拟器允许本地ADB连接。
3. 双击 **Check.cmd**。程序只检查环境、连接和画面，**不会点击游戏**。查看生成的 `latest.png`，确认账号和界面正确。
4. 双击 **Start.cmd**，确认提示后输入 **START**。随后脚本在后台运行，状态见 `STATUS.md`。
5. **Stop.cmd** 请求停止输入，不退出游戏。通常数秒内停止，遇ADB卡顿则等待当前调用结束。

自动检测不到模拟器时，将 `config.example.json` 复制为 `config.json` 并编辑：

- `adb`：MuMu自带 `adb.exe` 的完整路径。检查程序会尝试常见安装目录和Windows已安装程序信息；找不到时需手动填写。
- `serial`：该实例的ADB地址。默认 `127.0.0.1:16384` 只适用于部分MuMu实例；**多开或不同版本必须核对实际端口**。
- `package`：游戏Android包名。默认 `com.stove.epic7.google`；国服/其他渠道可能不同，且UI也可能需要适配。
- `strict_single_device`：默认禁止多设备情况下直接运行；明确核对目标serial后，才考虑改为false。

环境不符合时会停止，不会自动修改模拟器、代理、安全设置或安装游戏。

## 卡关、停止以后怎样续跑

**不要清空 `state.json`，不要删掉入场记录强行重试。**

- 如因网络或未知弹窗停止，先手动恢复到大厅/主线，再运行 `Resume.cmd`，输入 **RESUME**。已有记录会被保留；不能确认安全时仍会拒绝续跑。
- 如曾战败或中途停止且已有入场记录，先在游戏中手动通过该关，然后在主线地图**点选原来这一关，确保它有绿色通关勾**，再运行 `Resume.cmd`。只有精确验证原关卡已通关后，才会记作“用户手动补过”并继续下一关。
- 不支持确认的特殊情况请保留 `STATUS.md`、`state.json` 和截图，请修改者检查，不要通过清空记录绕过。

## 资源与重复入场保护

- 只允许关卡正常入场体力；遇体力购买/道具兑换提示不确认。
- 战败停止，不付费复活/续战，不自动重新挑战；不擅自培养角色、强化装备或更换队伍。
- 入场前核对章节、关卡、蓝色当前节点、绿色通关勾/锁；地图→辅助→队伍保持校验链。
- **先写入“本关已尝试”记录，再只点一次进行任务**。异常重启后不会因结果不明而再次入场。
- 仅对已识别的剧情跳过、胜利结算和免费通知进行对应操作；陌生确认框保守暂停。
- 好友申请提示只点取消，不自动发送好友申请。
- 网络重试与关卡重试分离，10分钟最多3次网络重连；不改系统代理。

不可能保证所有界面、维护或网络条件下都零故障；请先短时间观察实际运行。请自行确认游戏使用规则与账号风险。本程序不包含反检测、绕过安全机制或修改游戏内存的功能。

## 你会看到的文件

- `STATUS.md`：运行状态、关卡、体力、停止原因；分别统计脚本通关与人工补过。
- `latest.png` / `latest-ocr.json`：本次最新画面和识别文字，均保存在本机。
- `state.json`：必须保留的账号运行记录；不要跨账号复用。
- `events.jsonl` / `evidence/`：动作与关卡证据。**以后再转发此文件夹时，应排除这些账号资料。**建议直接转发原始干净ZIP。
- `runner.py` / `supervisor.py`：可编辑源码和有界重启守护。

**分享包只含本地脚本和守护，不包含Codex定时巡检，不会自己修BUG。** 未知界面需要人工处理；本机运行时电脑、MuMu应保持开启，不要休眠，也不要同时手动操作游戏。

## 源码小包

源码版不含 `python/` 与 `vendor/`。需要Windows x64的Python 3.12，先在此目录执行：

    py -3.12 install_dependencies.py
    py -3.12 launcher.py selftest
    py -3.12 launcher.py check
    py -3.12 launcher.py start

安装器只下载公开Python依赖，**先清除代理环境走直连，直连失败才回退到原代理设置**。不会改全局代理。

第三方依赖和Python许可证随完整版保留在各自目录。此包不附带MuMu的ADB二进制，需要使用收件人本机安装的MuMu。出现缺少DLL等环境错误时保留错误信息，不要从不明网站下载DLL替换系统文件。
