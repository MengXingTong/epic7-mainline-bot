# Steam 客户端适配验证 — 2026-11-09

状态：**v1.4.16-preview 收录实验性 Steam 发现与 PC 后台采集适配；尚未验收 Steam 游戏内输入接受或完整任务。** 不覆盖原 v1.4.15 ZIP，不把 STOVE 的既有实测结果套用于 Steam；本版发布检查另见 `RELEASE_VALIDATION_2026-11-09.md`（包内 `MAINLINE_VALIDATION.md`）。

## 实现范围

- `pc_clients.py` 集中维护已核实的精确游戏文件名：STOVE 的 `EpicSeven.exe` 与 Steam 的 `EpicSeven_Steam.exe`。大小写不敏感，不根据安装目录、标题单独放行；Steam 启动器、网页进程、覆盖层和相似前后缀进程不在名单中。
- 统一助手保留“电脑客户端”选项，实例标签区分 Steam/STOVE，明确标为实验性。发行渠道仅是展示信息，不是账号身份；不增加独立的 Steam 空进度、账号核查页或自动登录/选服流程。
- 两种发行渠道共享现有 PC 后台窗口消息适配。保留准确路径、HWND、PID/创建时间、`GLFW30` 窗口类、位置/尺寸/DPI、最小化、帧新鲜度、实际按住输入、STOP 和关键证据/意图写盘保护。未知窗口类和未知画面不因 Steam 兼容而放行，不抢焦点、不移动系统鼠标，不注入、不回退前台或绕过权限。
- 统一任务入口与主线的独立 `PcBackend` 路径均可绑定 Steam 游戏窗口；历史 `stove_pc` 配置名保持兼容，旧 CLI 的精确进程校验也同步名单，但旧 CLI 不作为推荐启动入口。
- 新模块纳入完整/增量包源码白名单与冷启动自检，隔离启动测试同步复制其真实依赖。未修改已有账号进度、运行请求、控制文件或活动任务。

## 本机只读现场

仅使用所选游戏窗口的后台采集和本地只读识别，不操作桌面/助手窗口，不进行游戏输入。

| 项目 | 结果 |
|---|---|
| Steam 游戏进程 | `EpicSeven_Steam.exe`，按真实可执行文件路径发现 |
| 游戏窗口 | 标题“第七史诗”，类 `GLFW30`，客户区 1280×720 |
| 状态 | 未最小化、失焦；不激活窗口 |
| 统一实例发现 | 展示 Steam 实验性标签，保留窗口/进程寿命身份 |
| 统一任务传输 | 连续3帧后台截图及 OCR 通过；当前视口为完整1280×720 |
| 主线独立后端 | 额外只读截图通过，未授予输入 |
| 当前画面 | 服务器选择页；3帧均识别为 `unknown`，零输入，不代选服务器 |
| 历史完整性 | 现场前后22份进度/目标关联/活动请求指针文件的 SHA-256 一致 |
| 费用/输入 | 未登录、未选服、未点击、未开战、未领取或消耗资源 |

私有截图、OCR、窗口路径/句柄、哈希报告与诊断日志仅保存在被忽略的本地目录，不纳入版本库、更新包或共享文件。

## 尚未验收 / 使用边界

1. Steam实际窗口消息是否被游戏接受、游戏内返回/导航/拖动、AUTO/2×和任务输入，均未实机验证。API投递不等于接受，接受不等于通关。
2. 未验证Steam主线、深渊、竞技场、剧场、次元、企鹅等完整业务和结算链；接入共用传输不等于所有任务已适配验收。
3. 未验证Steam其他语言、尺寸/DPI、跨显示器、长时间遮挡或其他机器；不支持最小化，不增加任何前台回退。
4. 使用者先自行完成登录与服务器选择，停在大厅或已知任务页，再在统一助手选择具体Steam实例。跨渠道使用同一账号须关联对应原记录，不能删除或新建空历史绕过旧失败/未决入场。
5. 旧助手/worker不会热加载；应正常停止并退出后重新加载当前源码。本项收录v1.4.16预览包；打包验证不重启游戏任务、不扩大实机范围。
