# 月光剧场 v1.4.9-preview 有限验收范围 — 2026-11-05

## 当前定位

月光剧场仅PC后台窗口消息适配，仍为实验性；不注入、不切前台、不代点系统授权。MuMu剧场、跨机器PrintWindow兼容、其他字体/缩放/窗口比例、跨剧目与长时间无人值守均未全面验收。
次元探查是另一个开发中实验项，不因本次打包变为全关卡通关版。

## 已有实机证据（打包前当前源码）

- 本机单个PC客户端，连续两集由各自唯一原入口/首次门票确认推进到剧情、领奖与独立完成行；后一集正常进入播放及战斗。发送成功、剧情播放、单独CLEAR均不充当完成证据。
- 当前库存小字的整行OCR偏低时，保留原词条，通用标签/数字在两个预处理视图中分别高置信复核后才补强；没有具体数字分支、历史库存替代或降低业务门槛。
- 正常已领取奖励关闭与返回页沿原证据链处理；完整N/N终波只消遮罩，不预记通关。N=1..99的等值与不等值由离线穷举回归覆盖，不宣称全部波次数均已实机看过。
- 已知页面有效控件、业务链和资源/窗口守卫齐全时，不等背景特效整屏静止；未知、黑帧、过渡及未知弹窗保持零输入。
- 原attempted/completed、入场发送意图、动作前缀、旧归档及证据均保留。一次人工明确授权的待确认接续只消费一次；私人授权、账号状态与证据不随包分发，新安装不会得到该许可。

原始画面、OCR、目标窗口身份、运行请求与实际操作审计仅保留在本机私有目录，本文不包含这些数据。

## 离线与包验证的区别

打包前完整源码回归857项，771通过、86因GUI运行库或私有素材缺失明确跳过；这不是全部兼容性通过。
本地包另需冷启动自检运行库、OCR模型、GUI布局、所有剧场/次元模块与资源；测试使用隔离临时目录，不发现客户端、不创建账号历史、不发送游戏输入。包自检及哈希结果在CHANGELOG/本地产物验证记录中说明。

## 使用边界

已有旧版应先停止任务并正常关闭助手，再覆盖更新原目录，不删除.local、state.json、evidence或对应原进度。
解压完整包也须关联正确的既有记录，不能以空历史重打旧关。正在运行的旧进程不会热加载。
容量、资源、付费、战败、未知弹窗、窗口/进程寿命/几何、最小化、过期帧与鼠标接管保护均保持；不购买体力/门票、不复活、不重试不明结果。
