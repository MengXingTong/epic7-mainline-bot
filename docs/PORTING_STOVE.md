状态：**已加入实验性原生后端与只读核对入口；默认关闭输入，尚未完成原生输入/新关结算实机验收。**

## 2026-11-02 已完成

- 已启动官方 PC 客户端、完成补丁，并按用户指示切换至正确服务器。服务器与账号的具体标识仅留在本机，不发布账号截图或进度。
- 通过桌面工具取得的私有地图截图，核验了已通关节点的绿色勾与下一未通关蓝色节点；同账号的旧失败记录原样保留，人工补过使用精确关卡证明补记。
- 实现 `pc_backend.py`：客户区截图、DPI/多屏映射、前台/遮挡/进程/尺寸变化检查，以及一帧只允许一次输入的护栏。
- 实现 `pc_launcher.py`：只读账号/服务器核对，显式实验启动/续跑，共享进度/进程锁，保留失败证据的人工补记。
- 抽离运行目录与源码目录：PC 复用已有账号状态，不覆盖 MuMu 的配置文件。ADB 仍是默认后端。
- **不要求全屏或固定显示器分辨率。** 正式坐标来自实际客户区；临时开发截图中的尺寸/标题栏裁剪不作为用户环境的固定配置。

## 验收条件

1. 通过 PCCheck 核验目标客户区截图及预期服务器/账号编号。
2. 实测不同普通窗口尺寸和 DPI；输入前目标变化必须取消，不强制全屏。
3. 确认同账号数据绑定及所有 attempted/completed/active/last_cleared，拒绝空记录和重复入场。
4. 仅选择新的、从未尝试且无勾/锁的关卡，完整匹配地图 → 辅助 → 队伍。
5. 在不兑换、不复活、不重试的前提下，验证一次入场、剧情、CG 和结算；结果不明即停止。
6. 需要认证、验证码或安全权限时交给用户，不自动处理。

使用细节及边界见 [PC 实验说明](PC_GUIDE.md)。
