# v1.2 当前默认行为（2026-11-02 更新）

用户明确要求取消账号/服务器识别和“仅观察”开关。默认路径为选客户端、实例和任务后直接点开始；不会自动打开菜单/账号设置，不填/读账号字段。原先的额外确认勾选也移除。内部维护自检仍可只读，但不出现在正常使用界面。

PC 显式授权到已选择的 HWND、PID、进程创建时间和可执行文件，保留客户区、DPI、焦点/后台模式、截图新鲜度及 STOP 校验。前台兼容等待用户手动切到游戏最多15秒，不自行抢焦点。MuMu 固定到所选 ADB 实例与游戏包。

已有历史原位读取，不改账号绑定元数据；首次开始仅在大厅/主线地图被识别后建立本机进度。原关手动补过仍须两帧精确关卡绿色勾与客户端守卫、CAS、备份及审计；补记不再读取账号或添加账号绑定。软件不再自动识别换账号，使用者必须选自己的原进度，不能通过空目录绕过已尝试关卡。

以下为此前版本的历史验收记录，其中“账号核对、默认观察”等描述不再代表 v1.2 的默认启动行为。

## 架构和旧入口

唯一UI负责选择客户端/实例/任务并锁定运行选择。内部worker可使用不同的既有运行库，这属于同一软件内部执行层，不另开功能窗口。MuMu与PC任务共用原主线锁；不会同时让旧脚本和新软件操作同一历史。

旧深渊目录仍保留为备份及历史证据，其 Launch.cmd 仅转到新UI。Git工程技术目录保留原名，不另建另一份软件。默认启动为观察模式，未请求本轮自动开刷。

本机完整离线回归185项通过；公开环境134项通过、51项明确跳过。

原主线的失败/未结算状态不会因统一UI、切换客户端或选择任务而清空；普通启动不会直接越过拦截，而是先自动核对同账号的原关卡绿色通关勾；连续两帧确认后追加手动通关记录并保留失败证据，核实不了就停止，不要求用户手改JSON。核对仅进行免费导航，不点击准备战斗或入场按钮。

PC后台模式是独立、显式选择的适配；前台适配的失焦保护未删除。任何消息/权限失败都会停止，不提升权限、不安装驱动、不注入、不改安全设置，不偷偷回退到前台抢输入。

## 手动补过后自动恢复

PC已实际通过账号核对、有限回看上一章、原关绿色通关勾双帧确认和新启动预检。本机账号已完成首次明确关联，后续自动比对，不要求日常填写服务器或账号字段。

普通推进前的验证分两层：GUI允许启动“核对流程”，不等于允许关卡入场；worker必须把原记录核对成明确手动通关，才解除旧关拦截。原始状态有私有备份，失败尝试、失败证据和审计均保留。错账号、资源弹窗、未过关、不可见的原关、陈旧或重复帧、STOP、历史并发修改都会阻止补记。无历史绑定时仍需首次明确确认归属，不自动套用。

MuMu账号导航与核对适配有模拟测试，尚未实机验收。跨Episode或原关不可见时需要用户在地图选中原关一次；不会为猜测旧进度而盲点或刷关。
