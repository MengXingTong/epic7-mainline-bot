# 第七史诗 · 统一推进助手 v1.4.4 预览分享版

Windows 64位离线软件，自带GUI、Python、OCR与识别资源。一个界面选择MuMu / PC、剧情关卡 / 普通深渊 / 圣女3-7，不用安装Python或API Key。

识别“英雄亲密度等级上升/提升”和本帧“轻触后关闭”，只关闭这层免费提示，再读取独立结算；不点击背后的下一层，不把弹层关闭当通关。主线、剧情和普通深渊共用识别，资源、付费、容量、战败与确认覆盖层仍优先。保留 v1.4.3 自动战斗等待修复；不包含未完成的次元探查开发项。

## v1.4.3 自动战斗等待修复

- 深渊纯等待不再因15秒未识别或单场累计20分钟而停机；未知画面持续取新帧、零输入，不把OCR空档当成游戏无响应。

## 使用

1. 完整解压到可写目录，不在压缩包里运行。自行登录游戏并准备好队伍与原生自动战斗；简体中文、16:9横屏，客户区至少640×360。MuMu需本机安装ADB；不含ADB、模拟器和游戏。
2. 双击“启动助手.cmd”。程序自动申请标准管理员权限，Windows UAC仍需本人点“是”；不会绕过/自动确认系统授权。已是管理员不重复申请。
3. 选择客户端、具体实例以及“推进剧情关卡 / 普通深渊 / 圣女3-7”，直接点“开始推进”。不识别账号/服务器，不导航账号页，无“仅观察”开关。仅打开软件不会开刷。
4. MuMu通过ADB后台运行；PC只使用后台窗口消息，不占用鼠标和游戏焦点，不再提供前台模式。PC仍为实验性，不能最小化游戏；多客户端必须手选实例。
5. 已有进度先“使用原进度…”关联原state.json，原位使用，不清空。暂停后可以继续；停止后再次点“开始推进”，从当前画面开始，不回查旧关或要求补记。
6. 装备/神器/英雄容量、体力或未知确认框显示黄色“等待处理”；手动处理后点“处理后继续”。不自动卖装备、扩容、购买、兑换或重新入场。
7. 等级提升全屏页自动点击下方继续区域；故事完成奖励只点击弹窗“点击关闭”。后台切屏短暂黑帧自动重取，期间不点击；连续10秒仍取不到画面则等待处理。

## 剧情关卡与圣女3-7

“推进剧情关卡”包含原主线：从大厅开始默认主线；已打开兼容老版支线时继续当前剧情。“圣女3-7”模式目前不能从大厅自动寻找支线。从大厅启动时，先在游戏内手动进入“支线 → 时间之书 → 圣女追悼文”的地区总览或关卡地图，再选择“圣女3-7”并开始；从当前进度推进，3-7成功结算后只循环3-7，不进3-8。不是自动解锁付费内容，也不会在大厅把普通主线误当圣女。

旧版地图按图标选关、准备页完整编号确认后再消耗正常体力。支持地图后台拖动、地区卡片、免费教学、三/五波CLEAR遮罩和蓝线出口。3-7每次有独立成功和入场记录；战败、不明结果不重复，其他关不循环。剧情体力不足在队伍页等待自然恢复，不购买/兑换；容量或未知弹窗仍等待处理。

## 持续推进，不设次数上限

界面不再有“本次最多推进”，主线和普通深渊没有关数或层数上限。旧limit=3/30等配置自动忽略，不用手工修改。任务持续推进，直到你暂停/停止、战败或遇到资源/容量/窗口/画面等需处理情况。不会因此购买、复活或重打已记录关卡。

## 地图误判修复

未读到右侧关卡星级时保留未知，不当成通关；已有入场记录也不代表完成。只有明确通关徽章或有标签的关卡星级证据才能自动选下一关，每一行均检查锁定。绿色背景、信用等级、英雄稀有度和章节总星数不参与通关判定。0～3星文字/★☆补充识别仅用于明确的通关星级标签，不承诺任意未见过的星形排版。当前关结果不明时显示原因，不误跳、不重打，不在地图与队伍页之间循环。

## 提速

导航动作后约0.45秒取新画面，新页面出现即可处理；同页未变化时保留切屏等待，不连点。战斗约2.5秒检查一次，网络重连保留原等待。间隔不含截图、OCR与游戏自身动画时间，不承诺固定倍数。预览先缩小再编码，减少无效开销。

顶部区分正在推进、正在恢复画面、暂停、等待处理、停止、完成和异常；说明文字不代表正在运行。STATUS.md只是报告，被占用只警告；state.json、证据或入场意图写入失败仍停止。

不再自动发现换账号/服务器，使用者必须选择对应原进度，不得以空记录绕过旧入场。仅上方普通深渊，不进入下方高难度。不购买、不复活、不改队伍或养成，不注入、不改内存或代理、不抢焦点。

运行后会在本机保存进度、画面、OCR和日志。**只转发原始干净ZIP，不转发用过的目录。** 发布包不含账号、配置、进度、完整截图、日志或凭据；只有通用锁图和19个二值战斗界面小图块。
