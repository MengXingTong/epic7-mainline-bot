# 第七史诗 · 统一推进助手 v1.2.1 预览分享版

Windows 64位离线软件，已附 GUI、Python、OCR 与识别资源。一个界面选择 **MuMu / PC 桌面端** 和 **主线 / 普通深渊**，不用安装 Python 或配置 API Key。

## 开始使用

1. 完整解压到可写目录；不要在压缩包内运行。
2. 自行登录游戏，停在大厅或主线地图，准备好队伍与原生自动战斗。要求简体中文、16:9 横屏，客户区至少640×360。MuMu需安装自己的ADB并允许本地连接；包内不含ADB、MuMu或游戏本体。
3. 双击 **启动助手.cmd**（或 Assistant.cmd），选择客户端、实例、任务和本次上限，**直接点“开始推进”**。不读取/核查账号和服务器，不打开账号设置，没有“仅观察”开关，也不用额外勾确认。只打开软件不会自动开刷。
4. 多个客户端时必须手动选实例，运行时锁定，不自动切换。PC后台仍为实验性，不支持最小化；PC前台兼容点击开始后最多等待15秒，由使用者将游戏切到前台，软件不会抢焦点。
5. 已有脚本进度时先点 **使用原进度…**，选择包含 state.json 的原目录；记录原位使用，不复制或清空。真正首次开始才自动建立本机进度，不需要账号绑定。
6. 暂停后可继续；停止不会关闭游戏或删除记录。运行库问题可运行 **SelfCheck.cmd**，它只检查运行库/模型/GUI，不操作游戏。

## 已有 v1.1 / v1.2 的更新方式

关闭助手后，将 v1.2.1 更新补丁内的文件解压并覆盖到旧软件目录。**保留 .local/、原进度、state.json 和 evidence/，不要删记录或改用空目录。** 新版会继续读取旧记录、忽略旧 observe=true；不再因为缺少账号识别而拦截。

完整包用于全新安装。使用过旧版本的人优先覆盖更新，避免忘记关联旧记录。分享包和补丁本身都不包含任何使用者的进度。

## 状态报告被占用

STATUS.md只是可读报告，不是进度来源。它被其他程序占用、只读或暂时无法替换时，界面显示黄色提示，任务仍可按已保存进度运行；后续保存会尝试恢复。**state.json、入场记录或证据写入失败依然安全停止**，不能忽略或删除关键记录。请以软件状态和state.json为准，不要因为旧报告未更新而反复开始。

## 进度归属

**不再自动识别账号切换。** 使用者必须保证选用当前游戏对应的原进度；不同账号请各用自己的软件/进度目录。不得为同一个账号新建空目录来绕过曾经失败或未结算的入场记录。已有绑定字段只是历史元数据，会保留，但不再做OCR匹配或自动换绑。

记录丢失、损坏、不完整或有STOP时拒绝重建。原失败关手动过后，会核对原章节/关号与两帧绿色通关勾，保留原失败/证据/备份并补记；无法核实就停止，不自动重试。

## 状态与操作边界

顶部固定显示未启动、检查中、等待游戏前台、正在推进、暂停中/已暂停、停止中/已停止、完成或异常。活动动画、更新时间和用时用于辨别实际运行状态；说明文字不代替状态。界面没有只观察开关，点开始就允许运行所选任务。

只推进上方普通深渊，不进入下方高难度。只允许正常关卡入场消耗，不买/兑换体力，不复活，不重试战败/结果不明关卡，不改队伍或养成。不自动处理登录/认证，不改代理或系统安全设置，不注入或修改游戏内存。

## 验证范围与限制

- 本次验证：无账号页导航的本机PC启动预检（未进新关，原进度摘要未变）；默认开始请求/窗口授权/保留历史/手动补记的离线测试；GUI布局与离线运行库资源自检。
- 不把上述预检说成整场战斗验收。PC后台完整连续推进、长时遮挡、拖动、CG长按，以及MuMu深渊仍未全面实机验收。陌生界面会停止；请先小上限试用，不适合未经观察就长时间挂机。
- 本次不更换截图或输入API，不保证修复其他电脑的PrintWindow/SetCursorPos限制，不会自动提权或回退到抢焦点输入。其他语言/渠道/不同游戏界面不保证兼容。

## 隐私和转发

原始ZIP不含账号、进度、完整截图、日志、设备配置、凭据或代理订阅。仅附通用锁图和19个去元数据的二值HUD小图块。

运行后会在本机保存进度、画面、OCR和日志；导入的原进度仍在原目录。**只转发干净的原始ZIP或补丁，不要转发使用过的目录。** 没有自动上传、自动更新、Codex巡检或自动修BUG服务。
