# 第七史诗 · 统一推进助手 v1.1 预览分享版

Windows 64 位离线包：已附 GUI、Python、OCR 与识别资源，不需要安装 Python、配置 API Key 或联网下载运行库。一个界面选择 **MuMu / PC 桌面端** 和 **主线 / 普通深渊**。

## 如何开始

1. **完整解压**到有写入权限的目录，不要在压缩包内直接运行。中文和带空格路径可用。
2. 先自行启动游戏并登录，使用简体中文、16:9 横屏（客户区至少 640×360）。MuMu 需安装自己的 ADB 工具并允许本地连接；分享包不附 ADB、MuMu 或游戏。
3. 双击 **启动助手.cmd**（或 Assistant.cmd）。首次默认 **仅观察**，不会点击游戏或建立关卡记录。出现问题可运行 **SelfCheck.cmd**；它只做离线运行库、OCR 模型、资源和 GUI 检查，不操作游戏。
4. 选择客户端、具体实例与任务。单个目标可自动识别；检测到多个时必须明确选择。运行中锁定实例，不自动切换。
5. 真正首次使用，取消仅观察，确认当前队伍和原生自动战斗，再点开始。首次会询问是否已有旧记录，随后自动导航到账号页做双帧核对；成功后建立收件人自己的本机记录，日常不用手填服务器/账号。
6. **已有脚本记录的同账号请先点“使用原进度…”**，选包含 state.json 的旧目录。记录原位使用，不复制、不清空；初次绑定需要确认归属，并自动核对账号及保留备份。账号不符、记录损坏/丢失会拒绝启动，不用空记录替代。

## 顶部状态怎么看

- **未启动**：当前没有任务在运行，说明文字不代表已开始。
- **检查中**：正在连客户端、核对账号/原关，尚未进入关卡。
- **正在观察 · 不会点击游戏**：只截图识别。
- **正在推进 · 主线 / 普通深渊**：任务正在执行，当前步骤与通关数在下方。
- **暂停中 / 停止中**：请求已发出，等待工作进程确认；不会假装已经停止。
- **已暂停 / 已停止 / 已完成 / 未运行·需要处理原因**：不再发送新的游戏操作。

活动动画、最近状态更新时间、运行用时用于区分“仍在工作”和“仅有一段提示”。暂停后点继续，停止后不会自动重启。

## 自动化边界

- 只推进深渊界面**上方普通入口**，不进入下方高难度挑战。
- 不买/兑换体力、不付费复活、不重试战败/未结算关卡，不重复进入本机已尝试/完成的关。
- 战败或未结算：先手动通过原关；支持的主线界面会自动核对同账号、原关和连续两帧绿色通关勾，保留原失败证据并补记。无法核实时停止；**绝不删除 state.json / STOP / 入场记录强行续跑**。
- 原 STOP 标记或无法安全确认的终止状态保留，需检查原因，不会自动清除。
- 不操作登录/认证，不自动切服，不改代理或系统安全设置。OCR 在本机运行，不上传画面。

## 兼容性：这是预览版，不是全场景保证版

- MuMu 使用 ADB，可不在电脑前台；游戏需在模拟器内部保持打开。主线有本机长期使用历史。
- PC 默认**后台窗口消息（实验性）**：PrintWindow + PostMessage，不抢焦点、不移动系统鼠标、不注入、不自动回退 SendInput；**不能最小化游戏**。前台兼容模式必须保持游戏前台。
- PC 无焦点截图/导航、主线手动补记与启动核对已有本机实测；**完整连续后台推进、遮挡压力、CG 长按、拖动等未全面验收**。MuMu 深渊及新的首次使用流程未在另一台干净电脑实机推进验收。陌生画面安全停止，不承诺所有设备可用。
- 本包验证包括干净中文/空格路径的运行库、模型和 GUI 启动；不等于完成全流程跨机器测试。请先观察、小上限试运行，勿用于无人值守长跑。
- 未经验证的服务器/语言/渠道界面不保证兼容。不同账号请各用独立目录，且各账号已有记录必须关联，不允许用新目录绕过旧入场记录。

## 隐私与再次转发

原始 ZIP 不含你的账号、进度、完整截图、日志、配置、凭据或代理订阅。附带的识别资源仅为通用锁图与 19 个二值化文字/HUD 小图块，不含账号或完整游戏画面。

运行后 `.local/` 会保存这个使用者自己的账号绑定、进度、画面、日志和证据（导入的原进度仍在原目录）。**请只转发原始干净 ZIP，切勿把用过的目录再压缩发给别人。** 移动整个未导入外部进度的便携目录可保留记录；已关联外部进度时须保留原目录。不要跨账号复用。

本包没有自动更新、Codex 定时巡检、自动修 BUG 或在线服务；电脑/游戏需保持运行。游戏规则和账号风险请自行确认，程序不绕过游戏保护或修改游戏内存。
