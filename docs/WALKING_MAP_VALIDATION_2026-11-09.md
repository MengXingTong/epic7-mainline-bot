# 主线共用行走地图适配与验证 — 2026-11-09

## 设计边界

本轮按用户要求复用圣女地图机制，而非针对“伊杰拉”或每一章添加名称白名单。`walking_map.py`只提供地图布局、短编号节点、地区/准备页身份和免费导航适配，`story_core.StoryController`继续负责原单次入场日志、战斗/蓝色出口、胜利过渡和独立结算。原 Episode 列表地图保持原路径，圣女循环仅由原显式任务控制。

- 地图：核对唯一准备控件、右侧任务/地区信息、底部成就/交易所、当前标题与数字节点；每个可见编号节点独立观察锁与可导航外观。紫色任务指针、绿/金色像素、星级总数均不构成完成事实。
- 短编号不是 `C-N` 或某个 Episode：以持久地区与节点编号形成独立键，并用当前准备页地区、完整实际编号和精确节点名绑定。不要求用户逐章录入，不猜章节号；不同地区同号节点分开保留。
- 地图证据、原始像素哈希、窗口/实例绑定、几何、run 与免费导航意图先保存。后续准备页必须与原 sent 导航源及当前地区/节点一致；仅发送不算目标已接受。地图源改变、历史冲突、真实目标/几何变化不放行。
- 缺失本run地图链的完整已知准备页先逐级原生返回；未知/不完整页面零输入。下一节点不在当前视野时复用有界后台平移；跨地区仅用当前原生已解锁入口，不凭缺少 N+1 发明下一章。
- 费用、唯一普通入口、完整准备布局和历史继续由原引擎核实；AUTO不是准备页门槛。可见零费用单次节点可以记录首次入场，不能因此补发或重播。
- 原 attempted/completed/active/last_cleared、归档、发送记录和证据均保留；显式新开始会完整归档原行走 active，不用旧链认领新结果，原入场/失败与防重复照旧。发现旧剧情/主线同节点历史时不以新布局空记录绕过；不把 sent/等待/点击/颜色当通关。只有原独立结算核实后更新该次完成。
- 普通主线没有关数上限。单个免费导航的未响应有界发送保护不是关数限制，更不允许重发资源入场。
