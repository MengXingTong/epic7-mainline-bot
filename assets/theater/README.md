# 月光剧场界面识别素材

`story.png` 是右上角回放/记录/暂停控制条，`battle.png` 是问号/倍速/自动战斗图标组。
来源为使用者提供的 `Epic7-Assistant-v1.2-preview.rar` 中同名剧场素材；仅提取这些小型通用界面图标，转为灰度并重新编码，不含原图片元数据、人物画面或账号信息。游戏界面图标不是本项目原创美术。

识别仅扫描标准 1600×900 画面的右上角 400×130 区域。参考包阈值分别为 .72/.70，本项目保留这些起点；已验证合成画面的正确位置、错误位置及缩放，尚无完整实机剧场画面可证明真实误识别率。

模板命中只用于区分已知剧情播放和战斗等待。资源、付费、容量、战败及未知确认仍优先；模板不能单独授权扣票、证明剧集身份或完成。

当前源码另包含不新增位图素材的限定位置几何核验：完整金色胜利徽章与1/1裁片OCR、战斗HUD及本轮播放链共同用于单次消罩，不能单独记完成；免费观览奖励需行内可获得奖励、唯一标签及向下箭头/托盘共同通过。位图模板本身仍不能授权入场、扣票或完成。当前仅验收第9集维护操作和私有截图回放，尚未端到端自动验收任意完整剧集或10张票连续任务。
